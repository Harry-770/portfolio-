Every developer I know has a half-finished portfolio somewhere. I had three. This year I finally shipped one, then rebuilt it three more times, because apparently I don't learn.

### v1: the Notion page

It took twenty minutes and it was fine. Honestly, it got me two clients. If you're reading this and stressing about your own site, start here. Nobody has ever said "nice portfolio, shame about the CMS".

### v2 and v3: the over-engineered ones

Next.js, MDX, a headless CMS, a design system with 40 tokens, for a site with five pages. I spent more time on the build pipeline than on the words. Lesson learned, mostly.

### v4: this one

Plain HTML, CSS and vanilla JS, plus Three.js for the space stuff. No framework, no build step. I can open it in five years and it will still run, which is more than I can say for v2.

The 3D is there because it's fun, not because it's necessary. I made sure the site works without it: if WebGL fails, you still get every word.

> Write the content first. Then make it pretty. Then stop.

I haven't managed the "then stop" part yet. You're looking at proof.
